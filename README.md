# Student HelpDesk

##  Project Overview

**Student HelpDesk** is a Python-based command-line application designed to help students connect with other students who can provide academic or skill-based assistance.

The system allows students to register themselves, add their skills, create help requests, find suitable student helpers, accept requests, complete requests, and maintain a history of completed help exchanges.

The project is developed as a beginner-friendly Python project and demonstrates the practical use of functions, modules, lists, dictionaries, file handling, JSON, validation, exception handling, searching, matching, and basic mathematical/data-processing operations.
